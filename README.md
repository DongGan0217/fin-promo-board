# 금융권 인사 보드

언론에 보도된 금융권(지주·은행·증권·보험·카드·캐피탈·저축은행·금고·금융공기관) 임원·본부장·부서장·지점장 인사를
회사별·시즌별로 정리한 정적 페이지입니다.

- 페이지: `docs/` (바닐라 HTML/CSS/JS, 빌드 도구 없음). 데이터는 `docs/data.json` 하나입니다.
- 내용은 언론 보도를 바탕으로 생성형 AI가 자동 정리했습니다. 정확한 내용은 각 항목의 원문 기사를 확인해 주세요.
- 지점장 지역은 지점명으로 추정한 값입니다.
- 회사별 바로가기: `#/company/<회사 ID>` (예: `#/company/kb_bank`)

글꼴: [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL 1.1), 아이콘: Material Symbols (Apache 2.0).
